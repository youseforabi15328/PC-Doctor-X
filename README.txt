PC Doctor X v2 — برنامج فحص وتشخيص حقيقي لويندوز
==================================================

المتطلبات: ويندوز 10 أو 11 + Python 3.9+ (python.org، اختر Add Python to PATH)

تشغيل سريع (بدون exe)
---------------------
1) افتح CMD في هذا الفولدر واكتب:   pip install psutil
2) دبل كليك على run_as_admin.bat  (يعطي قراءات أدق للحرارة والأقراص) أو run.bat

عمل ملف exe
-----------
دبل كليك على build.bat  ثم خد الملف من:  dist\PCDoctorX.exe
(يطلب صلاحيات المسؤول عند فتحه. لو عايزه من غير صلاحيات احذف  --uac-admin  من build.bat)

الميزات
-------
1) المراقبة الحية: المعالج والذاكرة والقرص والشبكة.
2) التسجيل المستمر: يسجّل المعالج والذاكرة والحرارة كل 5 ثوانٍ مع رسم بياني وتصدير CSV (%APPDATA%\PCDoctorX\logs).
3) الفحص الشامل (11 جزءاً): النظام، المعالج، الذاكرة، الأقراص (مساحة/صحة/استهلاك/حرارة)، كارت الشاشة، الدرايفرات،
   الأمان، برامج الإقلاع ووقت الإقلاع، الشبكة، البطارية، وتحليل الأعطال + نصائح الترقية. يعطي درجة من 100.
4) الأداء (Benchmark): سرعة المعالج (نواة/كل الأنوية)، الذاكرة، والقرص، مع مقارنة بآخر اختبار.
5) اختبار الإجهاد: تحميل المعالج 30–120 ثانية ومراقبة الحرارة وكشف الـ Throttling مع رسم بياني.
6) تحليل الأعطال: الشاشات الزرقاء (مع تفسير الكود)، الإيقاف المفاجئ، أخطاء العتاد WHEA، أخطاء القرص، وانهيار البرامج.
7) العمليات: أثقل البرامج لحظياً مع زر إنهاء (العمليات الأساسية للنظام محمية).
8) الصيانة: تنظيف الملفات المؤقتة، إفراغ السلة، تصفير DNS، SFC، وفتح أدوات ويندوز (الإقلاع، التحديثات، إدارة الأجهزة).
9) أكبر الملفات والمجلدات: تحليل مساحة أي مسار.
10) فحص أسبوعي تلقائي عبر Task Scheduler مع إشعار عند تدهور الحالة (الأمر: PCDoctorX.exe --scan).
11) التقارير: حفظ تلقائي، مقارنة تقريرين، توقع امتلاء القرص واستهلاك الـ SSD، تصدير PDF وJSON، ووضع فاتح/غامق.

أين تُحفظ البيانات؟
-------------------
%APPDATA%\PCDoctorX\reports  (تقارير JSON)  |  %APPDATA%\PCDoctorX\logs  (تسجيلات CSV)

ملاحظات
-------
- البرنامج لا يرسل أي بيانات خارج جهازك؛ الخادم المحلي يرفض أي طلب من خارجه.
- حرارة المعالج لا تدعمها كل الأجهزة. إذا تعذّرت القراءة يكتب البرنامج ذلك ولا يختلق رقماً.
- تصدير PDF المباشر يحتاج Edge أو Chrome (موجودان غالباً)، وإلا استخدم زر الطباعة من صفحة التقرير.
- قراءة القرص في الـ Benchmark تقريبية لأنها قد تتأثر بكاش ويندوز؛ سرعة الكتابة أدق.
- توقعات الامتلاء تحتاج 3 فحوصات شاملة على الأقل على مدى يوم أو أكثر.
- قد يعرض SmartScreen تحذيراً لأي exe غير موقّع رقمياً؛ اضغط More info ثم Run anyway.
